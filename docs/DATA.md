# 2부 데이터 확인 (2026-10-16, 1차)

조사표를 직접 연 것은 한국복지패널 18차 지침서뿐이다. 사회통합실태조사·사회조사 2023 조사표(hwp·PDF)는 열지 못했다. "2차"는 요약·검색에서 얻은 것, "미확인"은 확인 못 한 것.

## 판단

수급 유형(선별 vs 보편)과 신뢰 문항이 한 데이터에 같이 있다고 **확인된 조사는 없다.**

- 복지패널: 수급 항목이 가장 정밀(기초보장 급여별·장려금·기초연금·장애수당·아동수당(14차~)·보육료). 대인신뢰 문항은 3년 주기(1·4·7·10·13·16차)라 **16차(2021 조사) 개인 단위가 1순위 후보.**
- 사회통합실태조사: 대인신뢰 q28(4점) + 사회보장 영역 + 공정성 영역이 함께 있어 유력하나, 개인 수급 경험을 묻는지·시도 변수 공개 여부는 조사표(hwp)를 열어 확인해야 한다. KIPA 아카이브에 sav·설문지 게시.
- 사회조사 2023: 사회 신뢰·단체활동·자원봉사 있음. 복지급여 수급 항목 없음. 공표 시도 단위.

대안: ① 복지패널 16차 개인 수급 이력 × 신뢰, ② 사회통합실태조사·사회조사의 시도 신뢰 × 시도별 수급률(행정통계) 결합. 시군구 결합은 시군구 변수가 공개될 때만.
