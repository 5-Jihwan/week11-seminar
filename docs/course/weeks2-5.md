## 확인 사항

- 지정 PDF가 원문이 아닌 것: 2주차 Hardin은 Ells(2018)의 해설 장이다. 장 쪽수가 없어 PDF 쪽수로 적었다.
- 이 논문들 가운데 11주차 5편의 이름을 직접 언급하는 곳은 없다(Krishna, Freitag, Lowndes, Mettler, Kumlin, Rothstein 전수 검색). 표의 닿는 문장은 주제상 연결이고 직접 인용이 아니다.
- 연표에서 사회자본을 결과로 보는 줄은 Glaeser 외(2002), Wollebaek & Selle(2002), Rupasingha 외(2006), Guiso 외(2008)이고, Putnam(2000)은 쇠퇴의 원인 탐색으로 결과 쪽 질문을 연다. 원인으로 보는 줄은 Coleman, Fukuyama, Burt이다.
- Lin(1999)은 스캔본이라 1·3쪽만 이미지로 읽었다. 쪽수 인용이 필요하면 Ji가 원본 PDF로 확인해야 한다.
