단계

  1. gate() 자료 선택. 문항이 있고 차원이 있는 조사만 보인다(7개).
  2. cgate() 개념화. 문장은 선택, 차원·수준은 필수.
  3. renderPanel() 팔레트. 주제(신뢰·참여와 연결망·제도 경험·공정성·지역·개인 특성)로만 묶는다. 역할은 붙이지 않는다.
  4. 끌기: 빈 곳에 놓으면 rolePop()(다섯 역할 동일 순서) → newNode(). 변수 위에 놓으면 그 변수에 묶임. 끌기가 안 되면 + 버튼.
  5. 잇기: tapNode() 두 번. 조절변수는 snapZV()로 손잡이 근처에 놓거나 손잡이 클릭 → attachZV().
  6. 매 변화마다 touch() → draw() → validate() → 배지, persist()(새로고침 복원), sendDraft()(3초 뒤 초안 전송), 10초 멈춤이면 배너.
  7. 서랍 넷: 변수(이 문항의 1부 자리) · 정의(개념화·조작화·간격·대안 정의) · 선행연구(칸·격자·국내 5·해외 5·전체 스크리닝·옆 사람·연구질문·제출) · 리뷰(약한 고리·한 단계).
  8. submit() → modelValue()를 localStorage w11_model과 워커로. 기기 ID(DEV)가 같으면 최신만 센다.

5. 규칙

5.1 구조 검증 validate() — 오류 6 · 경고 7 · 정보 4

등급조건뜻
오류종속 없음 / 독립 없음 / 문항 없는 변수 / 종속에서 나가는 경로 / 매개→독립 / 조절변수로 들어오는 화살표 / 조절이 잘못된 경로 위제출이 잠긴다

5.2 개념·측정 간격 gap()

개념 dim과 종속변수 문항들의 dim 집합을 비교한다. 인지적이라 했는데 구조적 문항뿐이면 경고, 반대도 경고, 둘 다라 했는데 한쪽뿐이면 정보. 수준이 공동체인데 지역 변수가 없고 조사 단위도 개인이면 정보. 종속에 dim 없는 문항(제도 경험·인구 특성)이 섞이면 정보.

5.3 분류 틀 cell()

종속 차원 dvDim() = 종속 문항들의 dim 집합(둘 다 있거나 both가 있으면 both). 원인 축 ivSrcs() = 독립 노드 문항 개념의 src 집합(src가 비고 dim이 있으면 'society'). 칸 이름은 "원인 축들 → 차원 사회자본 · 개인/공동체". 같은 칸의 1부 논문은 PAPER_CELL 표(Krishna 사회·지역/both, Freitag 제도/구조, L&W 제도/both, Mettler 제도/구조, K&R 제도/인지)에서 원인 축이 겹치고 차원이 같거나 both면 뽑는다. 선행연구 편수는 같은 조건으로 STUDIES를 센다(연구 쪽 차원은 comps로: trust·reciprocity → 인지, 나머지 → 구조).

5.4 유사도 screen() — 최대 11점

항목점조건
구성 요소 겹침0~3자카드(겹침/합집합)×3. 0이면 등급 '무관'

5.5 대안 정의 altDefs()

셋을 만든다. 마지막에 묶은 문항을 빼면 → 1위 연구가 바뀌나. 같은 조사의 다른 사회자본 문항을 더하면 → 바뀌나. 같은 개념을 다른 조사로 재면 → 척도·단위가 어떻게 다른가. topFor()는 자카드와 단위만 쓴다(단순 비교용).

5.6 리뷰 review()

조사별 기본 카드 2장(REVIEWS: 약한 고리·한 단계) + 조건 카드(COND 10: 매개 있음, 공정성 매개+사회통합, 기관신뢰 종속, 선별 수급+복지패널, 선별 수급+지역사회건강, 참여 제도+사회통합, 지역(시군구/광역), 연구질문에 "영향", 이웃 신뢰+복지) + 조절 있음 1장.

5.7 가설 hyps()

경로마다 "A은 B와 관련이 있을 것이다". 조절(toEdge)은 그 경로의 "A과 B의 관계는 Z에 따라 다를 것이다". 매개는 들어오는 변수마다 "A과 D의 관계를 M이 매개할 것이다". 종속에서 나가는 것, 통제가 낀 것은 빼고, 학생이 고친 문장(hypEdits)이 우선한다.

9. 약한 곳과 판단이 필요한 곳

점수 가중치는 임의다. 3·1·1.5·1·1·2·0.5·1은 "구성 요소가 제일 중요하고 같은 자료가 그다음"이라는 판단을 숫자로 적은 것이지 추정된 값이 아니다. 11-08부터 유사도 패널과 서랍에 이 사실을 고지한다. 검수 50편이 끝나면 "사람이 닮았다고 한 쌍"으로 가중치를 다시 잡아야 한다. 논문에 쓸 때는 반드시.
규칙 코딩의 연결망 과다 → 해소. 11-07 Haiku 5.5가 7,569편을 다시 코딩해 규칙 코딩의 넓은 "네트워크·교류" 패턴을 대체했다. 남은 한계는 AI 코딩 자체의 오류이며 사람 검수(verified) 0편.
'사회자본이 종속' 단서 → Haiku 판정 1,903편. 문구 패턴 723편 대신 초록을 읽은 판정으로 바꿨다(국내 610·해외 1,273). 판정이 N인 연구에는 「사회자본이 원인 쪽일 수 있음」 표시가 남는다.
원인 축 '사회 중심'의 정의가 약하다. 캔버스에서는 "dim이 있는 문항을 독립변수로 쓰면 사회 중심"이고, 연구 쪽은 iv_network=Y면 사회 중심이다. 둘 다 Hooghe & Stolle의 "결사체·공동체 경험이 원인"을 대충 흉내 낸 것이라, 토론 때 교수님이 짚으실 수 있다.
단위 판정. 내 단위는 '개인'이 기본이고, 지역 원인을 개인 응답에 붙이면 '다수준'(11-08). 선행연구의 지역·다수준 단위와 맞으면 가산한다. 복지패널의 가구·가구원 섞임은 경고만 한다. 다수준 설계의 세부(임의효과·집계 방식)를 표현할 자리는 없다.
크기 → 분리. 11-08부터 선행연구 7,690편은 studies.js(4.6MB)로 따로 비동기 적재하고 canvas.html은 0.43MB. 화면이 먼저 뜨고 유사도는 받은 뒤 센다(그 사이 「불러오는 중」). GitHub Pages가 압축해 보내므로 실제 전송은 1MB 안팎.
옆 사람·판정은 같은 브라우저(데모) 또는 워커(수업)에서만. localStorage 모드에서는 다른 폰이 안 보인다. 워커는 코드만 있고 배포 전(Ji 계정, wrangler deploy + PIN 시크릿). 같은 자료로 사회자본을 결과로 본 선행연구가 0편이면 유사도 패널이 「당신이 첫 사례일 수 있다」고 말해 준다(11-08).
그물망 1,200편 상한. 국내가 먼저 들어가 해외 코딩본 일부는 그물망에 없다(전체 스크리닝에는 있음). 설명 문구에 적혀 있다.
괜찮은 곳. 상태가 하나(st)라 복원·되돌리기·제출이 같은 객체를 쓴다. 규칙은 전부 순수 함수(validate·gap·cell·screen·hyps)라 테스트와 대시보드가 같은 값을 본다. 서버는 행 저장뿐이라 와이파이가 끊겨도 화면 로직은 전부 돈다. 선행연구는 목록 밖에서 나올 수 없다.
