【글】무엇을 사회자본으로 재겠습니까. 개념 8개 버튼. 각 버튼 아래 작은 글 "1부: Krishna 마을 단위 신뢰" 식(§3-1의 한 줄).
【글】(하단) 1부 다섯 편도 여기서 갈렸습니다.

**S2 문항 (2/6)**
【글】그 개념을 묻는 문항입니다. 하나를 고르십시오. 조사별로 접힌 목록, 펼치면 원문·척도·연도·단위.
복지패널 대인신뢰에는 "3년 주기(13·16차)" 표시, 이웃 신뢰는 문항 하나라 자동 선택 후 바로 S3.

**S3 독립변수 묶음 (3/6)**
【글】무엇이 그것을 바꾼다고 보십니까. 하나 이상. 묶음 4개 + 지역. 회색 묶음은 흐리게, 누르면 §3-3의 글.
【글】(개인 특성 칸) 연령·교육·소득·고용은 모든 모형에 들어갑니다.
복지패널이면 묶음 옆에 "가구 단위" 표시.

**S4 매개 (4/6)**
【글】가운데 무엇을 거친다고 보십니까. 공정성 지각 / 기관신뢰 / 없음. 종속이 기관신뢰면 기관신뢰 버튼을 숨김. 같은 조사에 없으면 회색.

**S5 연구질문 (5/6)**
【글】한 줄로 적어 주십시오. 예: "기초생활보장 수급 심사 경험은 대인신뢰와 관련이 있는가". 비워도 됩니다.
인과형 예시는 두지 않는다. "영향을 미치는가"를 쓰면 막지 않는다(spotlight ③의 재료).

**S6 모형 그림 + 제출 (6/6)**
그림: 왼쪽 상자 묶음(고른 독립 묶음 + 개인 특성, 특성별로) → 가운데 매개 → 오른쪽 종속. 각 상자 안에 문항 요약 한 줄. 아래 "자료: ○○조사 ○년 · 단위: 종속 가구원 / 독립 가구"처럼 단위가 둘이면 둘 다.
【글】[제출]. 제출 뒤 수정 불가 안내.

**S7 결과 카드 (제출 뒤)**
세 장이 차례로 열린다(아래로 스크롤).
- ① **당신의 모형**: S6 그림 + 문항 원문 전체.
- ② **어느 논리인가**: §5의 판정 결과 한 줄 + "1부 ○장에서 본 논리입니다" 또는 "1부 다섯 편 밖의 조합입니다".
- ③ **약한 고리와 한 단계**: §6의 규칙 카드(자료 설계 + 조건). 1부 어휘를 굵게.
세 장 아래: "1부 다섯 편이 사회자본을 잰 것" 표(P2와 같음). 선행연구 카드는 없다(§0-2).

## 6. 리뷰 규칙 (카드 ③, model/reviews.json)

키 = 종속을 고른 조사 + 조건. 조사 7개 기본 카드 + 조건 카드 10개 = 17개. 조건 카드는 기본 카드 아래에 덧붙는다. 1부 어휘는 괄호 안의 장.

**기본 카드 (조사별)**

- **복지패널 16차** — 약한 고리: 16차는 아동수당이 이미 보편인 해라 심사의 효과가 안 보입니다(5장 역인과와 다른 문제: 변이 없음). 신뢰는 가구원, 수급은 가구라 단위가 다릅니다. 한 단계: 14차(2018, 선별 시기)와 16차를 같은 사람으로 이으면 전환 전후 설계(5장 연구자 자리 B)가 됩니다.
- **사회통합실태조사 2023** — 약한 고리: 한 해 횡단면이라 신뢰가 낮아서 접촉을 피했을 가능성(5장 역인과, 355쪽)을 못 가릅니다. 수급 문항이 없어 제도 설계 효과는 못 잽니다. 한 단계: 2021~2025 다섯 해를 쌓아 추세를 보거나, 공공서비스 만족(5점)을 K&R 매개 자리에 둡니다.
