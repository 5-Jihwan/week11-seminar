# 2부 진행 플랜 (2026-11-13 재설계) — 45분, 2:15~3:00

덱은 `deck/week11_part2.html`(12장: 본편 10 + 부록 2, 빌더 `deck/build_part2.py`). 학생은 QR로 캔버스, 프로젝터는 덱과 대시보드(프로젝터 모드)를 오간다. 대시보드는 Ji 노트북 하나에서만 연다(KV 무료 한도. backend/README.md).
이전 판(대시보드 기능 시연 중심: 분류 틀 칸·판정 버튼·연결망 되감기)은 `deck/archive/`. 이번 판은 만들기와 이야기에 시간을 쓴다.

## 아침(오전 9시 이후)

1. 대시보드 열고 PIN → 위쪽이 「워커」인지.
2. 폰으로 캔버스에서 제출 1건 → 대시보드에 뜨는지.
3. 「비우기」 → 「서버 기록 n건을 지웠습니다」 → 0행(11-09 시험 기록도 함께 지워진다).

## 잘못될 때

| 상황 | 대응 |
| --- | --- |
| 대시보드 「연결 실패」 | 새로고침 후 PIN. 그래도 안 되면 Downloads의 `2부_오프라인판_20261112`에서 canvas.html과 dashboard.html을 같은 브라우저로 열고, 학생이 말하는 문항을 Ji가 넣어 제출 |
| 와이파이 끊김 | 이미 연 학생 화면은 계속 작동, 제출만 안 됨. 이야기 시간에는 학생 화면을 직접 보며 진행 |
| 끌기가 안 되는 폰 | 문항 카드의 ＋ 버튼 |
| 자원자 없음 | Ji가 다른 자료·다른 종속변수를 고른 분을 모신다 |
