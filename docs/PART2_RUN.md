# 2부 진행 플랜 (2026-11-13 재설계) — 45분, 2:15~3:00

덱은 `deck/week11_part2.html`(11장: 본편 9 + 부록 2, 빌더 `deck/build_part2.py`). 학생은 QR로 캔버스, 프로젝터는 덱과 대시보드(프로젝터 모드)를 오간다. 대시보드는 Ji 노트북 하나에서만 연다(KV 무료 한도. backend/README.md).
이전 판(대시보드 기능 시연 중심: 분류 틀 칸·판정 버튼·연결망 되감기)은 `deck/archive/`. 이번 판은 만들기에 시간을 쓰고, 모형 발표 없이 대시보드를 가볍게 함께 본다.

## 아침(오전 9시 이후)

1. 대시보드 열고 PIN → 위쪽이 「워커」인지.
2. 폰으로 캔버스에서 제출 1건 → 대시보드에 뜨는지.
3. 「비우기」 → 「서버 기록 n건을 지웠습니다」 → 0행(11-09 시험 기록도 함께 지워진다).
