# 11주차 발제 세부 기획

최종 갱신 2026-10-16. 이 문서와 `CLAUDE.md`가 기준이다. 아래 "폐기된 결정"에 있는 것은 다시 꺼내지 않는다.

## 1. 전체 그림

11주차는 강의 축이 뒤집히는 주다. 6~10주차는 사회자본을 독립변수로(→ 민주주의, 정부 성과, 경제 성장) 놓았고, 11주차에 처음 종속변수가 된다(제도·정책 → 사회자본). 4주차 Formation(문화·개인 투자·인구 구성)과 짝을 이루며, 오늘의 답은 "국가"다.

5편은 1993년 Putnam 『Making Democracy Work』("사회자본은 역사가 정한다")에 대한 1996년 비판(Levi, Tarrow, Foley & Edwards, Skocpol — "정부는 어디 갔나")의 답안지다. 계보는 둘이다.

- 정치학 계보: Lowndes & Wilson, Freitag, Krishna (Levi·Tarrow 인용)
- 정책환류 계보: Mettler, Kumlin & Rothstein (Pierson 1993, Soss 1999 인용)
- 두 계보를 잇는 이름은 Skocpol 하나 (Freitag, Mettler만 인용)
- Levi 1996은 5편 중 4편이 인용 (Mettler 제외)

제목 장치: 1985 *Bringing the State Back In*(Evans·Rueschemeyer·Skocpol) → 2002 Mettler *Bringing the State Back In to Civic Engagement* → 2006 Freitag *Bowling the State Back In*(Putnam *Bowling Alone*과 이중 패러디). 번역하지 않고 바뀐 동사만 보여준다.

## 2. 1부 (105분) — 논문 세미나 + 시뮬레이션

### 2-1. 진행 원칙

- 강의형 세미나. 다 읽고 온 사람들 앞에서 핵심을 짚고 "나라면 어떻게 했을까"를 묻는다. 요약 슬라이드 없음.
- 참여는 지명. Ji가 17명 이름을 다 안다. 질문은 고르기 형식(찬반이 아니어도 됨)이 기본.

### 2-4. 논문별 설계

#### 1. Krishna (2007) — 사회자본은 7년 만에 움직인다

- 짚기: Table 2. 정부 조직 7.42, NGO 조직 3.31 비유의 / 주민 자생 조직 17.57*, 규칙 3.77*, 신진 리더 5.59* (Model 2, N=60, R²=.79 — 원문 대조 완료, docs/PAPERS.md §1). 원문 "socially generated through the internal efforts of community groups"(941). 저자 자신이 "같은 국가 제도 아래라 제도 설계 효과는 검증 불가"라고 씀(950) → Freitag로 넘기는 근거.
- 시뮬 1장 「마을 7년」: 외부 NGO 모임 vs 친구가 만든 모임 / 문제 생기면 카스트 어른 vs 읍사무소 서류를 아는 30대 청년. 7년 후 마을 점수.
- 반전: "이 결과는 라자스탄 61개 마을에서만 확인됐다. 서울이라면?"
- 연구자 자리: "라자스탄 마을 사회자본을 재야 한다. 어떤 질문을?" A 단체 몇 개 가입 / B 가뭄 때 이웃이 도울까 / C 공동 경작 문항. Krishna는 A를 버림(공식 조직 가입률이 극히 낮음) → 맥락 문항 6개 지수(944–946).
- 한국 적용: 마을 → 아파트 단지, 자생 조직 → 입주자대표회의 자생 여부, 신진 리더 → 동대표 연령.
- 소환: 3주차 Bourdieu 발표자(장진) — "축적된 역사가 7년 만에 움직였다. Bourdieu라면?"
- 넘김: "내부 리더가 키운다면 국가는 할 일이 없나. 스위스로 갑니다."

#### 2. Freitag (2006) — 제도인가, 언어권인가

- 짚기: Table 6. 직접민주주의 Model 1 .47*** → Model 5(언어권 포함) .18 비유의, 언어권 .38**. 각주 10 r=.86 (원문 대조 완료). 반전 보강: 최종 Table 7에서 저자는 직접민주주의와 언어권을 같은 모형에 아예 넣지 않았고, 통제 둘(도시화·언어권)만 넣은 Model 2의 R²(.79)가 제도 셋만 넣은 Model 1(.75)보다 높다. 종속변수는 결사체 참여만, 신뢰는 통제변수("from trusting to joining", 134)인데 다변량에서 비유의.
- 시뮬 2장 「이사」: 주민투표가 잦은 지역 / 득표율대로 집행부를 나누는 지역 고르기 → 참여 막대 상승.
- 반전: 숨은 변수 공개 — "당신이 고른 지역은 전부 독일어권이었다."
- 개념 고르기(합의민주주의): 학생회 선거 이긴 쪽이 집행부 독차지 vs 득표율대로 모든 과가 집행부 참여. 어느 학교에 동아리가 많나. 답 B.
- 연구자 자리: "직접민주주의와 독일어권이 겹친다. 어떻게 떼어내나?" A 둘 다 넣기(Freitag, 효과 소멸) / B 독일어권 안에서만 비교 / C 제도 변화 전후. N=24로 할 수 있는 한계 체감 → 2부 예고.
- 한국 적용: 칸톤 → 시군구, 직접민주주의 → 주민투표·주민발의 건수, 언어권 → 수도권 더미.
- 소환: 2주차 Olson 발표자(박민지) — "직접민주주의가 선택적 유인으로 읽히나?"
- 넘김: "제도가 만든다고 치죠. 어떤 설계가요?"

#### 3. Lowndes & Wilson (2001) — 제도 설계의 네 차원

- 짚기: "Social capital may remain a 'latent' phenomenon in the absence of responsive political institutions"(638). 네 차원: 자발부문 관계 / 시민 참여 기회 / 의사결정 반응성 / 민주적 리더십·포용.
- 시뮬 3장 「구청장」: 예산 한 항목분 — 주민단체 보조금 / 시민배심·토론회 / 주민 제안 30일 내 응답 의무화 / 평일 저녁·온라인 창구. 사회자본이 회색(잠재) → 색(동원)으로 바뀌는지. 응답 의무화를 안 고르면 참여가 반짝했다 꺼짐.
- 반전: "이 장의 숫자는 전부 가정이다. 저자도 해본 적이 없다."
- 개념 고르기: 사회자본은 설계도대로 짓는 건물 vs 물 주고 기다리는 화단 — 저자의 "institutional gardening vs engineering"(645).
- 한국 적용: 반응성 → 민원 처리 기간, 동원된 사회자본 → 주민참여예산 제안 건수.
- 시간 부족 시 가장 먼저 줄인다.
- 넘김: "그럼 실제 정책 하나를 봅시다."

#### 4. Mettler (2002) — 정책은 돈과 메시지를 같이 준다

- 짚기: G.I. Bill 이용 → 단체 가입 .47, 정치 참여 .38 (학력 통제 후, Table 1·2). Figure 1 자원 효과 / 해석 효과.
- 시뮬 4장 「등록금」: 같은 400만 원을 "신청서 한 장, 다음 달 입금"(누구나·서류 없이·즉시)으로 받을지 / 소득·재산 심사 뒤 받을지 **무작위 배정**. 이후 참여 의향 질문 → 두 집단 비교. 강의실 실험 1회. ⚠"권리" 안내문은 쓰지 않는다. 참전자들은 G.I. Bill을 권리가 아니라 특권·선물로 여겼고(358), 해석 효과는 집행 방식에서 왔다(360 "You just enrolled").
- 반전: 50년 뒤 "그때 얼마나 활동했나"를 묻는데 기억이 기록과 어긋남(회고 편의).
- 연구자 자리: "1998년에 1950년대 참여를 재야 한다." A 회고 설문(Mettler, landmark event 논리로 방어) / B 옛 명부 / C 포기.
- 한 가지 더: 최저층(1920년대 생활수준 '저')은 단체 가입(Table 6)·정치참여(Table 7) 모두 비유의. 저중은 둘 다 유의, 정치참여는 상위층(1.22, p=.00)이 가장 큼 — "왜 가장 가난한 사람에게는 안 통했나" → 14주차 Dark Side 예고.
- 표본: 4개 부대 참전자회, 응답 716명(73.5%), 백인 98.5%.
- 한국 적용: G.I. Bill → 국가장학금·청년내일채움공제, 시민참여 → 투표·단체 가입.
- 넘김: "정책이 만든다면, 부술 수도 있나요?"

#### 5. Kumlin & Rothstein (2005) — 선별은 신뢰를 깎는다

- 짚기: Table 5 선별 기관 접촉 1곳당 −.26, 보편 +.07 (둘 다 p<.01, N=2,543). Table 3 평균 6.7 → 6.0 → 5.7. 매개는 공정 대우 지각(Table 7, 6개 기관 중 4개 유의). 서부 스웨덴 SOM 1999. 토론감: 매개 문항 "받을 자격이 있는 것을 받았나"(356)는 절차보다 결과에 가깝다.
- 시뮬 5장 「복지 창구」: 아동수당 — 2018년 9월 도입 때는 소득 증명 후 수령(하위 90%), **2019년 1월부터** 소득 기준 폐지(그냥 수령). 2019년 9월은 만 7세 미만 연령 확대이지 보편 전환이 아님. 신뢰 막대가 두 해에 다르게.
- 반전: 오프닝에서 각자 답한 0~10 신뢰를 "타고난 신뢰"로 공개 — "원래 신뢰가 낮아서 이 창구에 왔을 수도 있다." 저자 자인 "the opposite is always possible"(355).
- 정책 담당자 자리: "아동수당을 상위 10% 걸러서 vs 모두에게." 다수는 A가 공정해 보인다고 답할 것 → K&R 논리로는 거르는 과정이 신뢰를 깎음. 한국이 2019년 보편으로 간 배경의 행정 비용 논란(수치는 확인 후 인용).
- 연구자 자리: "방향을 어떻게 가르나?" A 같은 사람 추적 / B 제도 전환 전후 비교 / C 실험. 5편 모두 못 했고, 한국엔 B가 있다(2019 전환) → 2부의 식별 대안.
- 넘김: "이 −0.26을 한국에서 다시 볼 수 있을까요. 쉬고 와서 직접 만들어 봅니다."

### 2-5. 엔딩 카드 + 마무리

각자의 사회자본을 개인 선택 / 제도 / 숨은 변수로 나눈 카드. 이어서 "무엇을 쟀나" 표:

| 논문 | 종속변수 | 왜 그걸 골랐나 |
| --- | --- | --- |
| Krishna | 집합행동 성향(자체 6문항) | 공식 조직이 없는 마을이라 회원 수는 무의미 |
| Freitag | 결사체 참여 | 신뢰 → 참여 방향을 가정해 신뢰는 통제 |
| Lowndes & Wilson | Putnam 혼합 정의 | 잠재와 동원을 구분 |
| Mettler | 단체 가입 수·정치활동 | 신뢰는 재지 않음 |
| Kumlin & Rothstein | 대인신뢰 | 참여 → 신뢰 증거가 약하다고 봄(Stolle 1998) |

"결사체를 재면 국가가 만들고, 신뢰를 재면 국가가 부순다." → 교수님께 넘김.

### 2-6. 지명 원칙

- 쉬운 고르기는 발표 안 한 사람, 연결 질문은 자기 발표 주차와 이어지는 사람(2주차 Olson→Freitag, 3주차 Bourdieu→Krishna, 4주차 Formation→축 뒤집기).
- 17명 거의 전원 1회, 2회 걸리는 사람 없게. 시뮬레이션 분포를 보고 "반대쪽을 고른 ○○ 원우"를 부르는 방식이 기본.
- 이름은 발표자 노트에만. 토론 계획서에는 쓰지 않는다.

## 3. 시뮬레이션 「한 사람의 사회자본」 — 기술 사양

- 학생 화면: 별명 입력 → 오프닝 3문항 → 1~5장 → 엔딩 카드. 막대 3개(신뢰·참여·관계). 챕터당 1~2분 분량.
- 진행 통제: `admin.html`에서 열린 챕터 번호를 바꾸면 학생 화면이 거기까지만 열림. 시간 초과 시 자동 선택.
- 저장(Apps Script → 시트), 한 행 = 선택 하나: `ts, nick, chapter, step, choice, condition, init_trust`
- 대시보드: 챕터별 선택 분포 막대, 4장은 배정 조건별 비교, 5장은 처음 신뢰 상·하위별 선택 교차.
- 4장 무작위 배정은 서버에서 별명 해시로 결정(재접속해도 같은 조건).
- 오프라인 모드: 한 기기에서 Ji가 클릭, 저장 없이 진행.
- 화면 하단 고정: "논문 결과의 방향을 따른 교육용 모형, 실제 추정치 아님".
- 디자인: 담백한 편집형, 모바일 우선, 포인트 색 1개.

## 4. 2부 (45분) — 연구모형 웹앱

### 4-0. 구상 (2026-10-16 Ji 확정, 아래 4-1~4-5보다 우선)

1. Ji가 국내 조사 csv·엑셀 + 조사표를 Google Drive 한 폴더에 올린다. 원자료는 메뉴를 만드는 데만 쓰고 학생에게는 가지 않는다(가드레일 3).
2. 조사표에서 사회자본으로 쓸 수 있는 **개념 전부**를 뽑아 `model/catalog.json`을 만든다. 한 항목 = 개념 · 설문 문항 원문 · 조사명 · 연도 · 변수명 · 척도. (대인신뢰, 기관신뢰, 단체 참여, 이웃 교류, 호혜, 공정성 지각, 선별·보편 수급 경험, 참여 제도 경험 …)
3. 학생은 그 목록에서 종속·독립·매개를 골라 **자기 연구모형**을 만든다. 그림 자동 생성(행정학 관행 형식).
4. 레퍼런싱: 닮은 국내외 선행연구 3~5편(코퍼스 규칙 매칭, verified만) + 선행연구들이 사회자본을 **어떤 데이터·어떤 문항으로 쟀는지**.
5. 관리자 탭: Ji와 교수님이 17명의 모형을 **실시간**으로 본다. 끝에 종속변수 빈도 · 측정 문항 빈도 · 선행연구 빈도를 나란히. Ji가 모형 하나를 **짚으면 프로젝터 화면에 크게** 떠서 설명한다(spotlight).

계수 사전 계산(4-1의 5, 4-4의 R 추정)은 **필수가 아니다**. 학생 산출물은 모형·레퍼런스·측정 빈도이지 추정치가 아니다. 시간이 남으면 조합 몇 개만 예시로.

### 4-1. 학생 흐름

1. 종속변수: 대인신뢰 / 기관신뢰 / 단체 참여
2. 독립변수 묶음: 제도 경험(선별·보편 수급, 참여 제도) / 개인 특성 / 지역 특성. 매개 0~1개
3. 연구질문 한 줄
4. 모형 그림 자동 생성(행정학 관행 형식)
5. 결과·리뷰: 사전 계산 계수 / 5편 중 어느 논리인가 / 닮은 선행연구 3~5편(코퍼스에서 규칙 매칭) / 인과가 약한 이유를 1부 반전 어휘로(외적 타당성·숨은 변수·실증 부재·회고 편의·역인과) / 한 단계 강하게 만드는 설계 하나(예: 아동수당 2019 전환 전후)
6. 제출 → 저장

### 4-2. Ji 대시보드

- 17명이 고른 조합 순위
- 같은 조합의 선행연구 편수와 설계 분포(횡단면 몇 %)를 나란히
- 질문: "왜 다들 이 조합을 고를까" → 데이터에 문항이 있어서 / 이론 관행 / 측정이 쉬워서
- 아무도 안 고른 조합 = 연구 빈자리

### 4-3. 시간

도입·접속 5 → 모형 만들기 10 → 리뷰 읽기 10 → 모아보기 15 → 정리·교수 총평 5.

### 4-4. 데이터

- 후보(MDIS): 사회통합실태조사(대인·기관신뢰·공정성), 한국복지패널(수급 유형 정확), 사회조사 2021·2023(단체참여·기관신뢰·시도), 지역사회건강조사(이웃 신뢰·시군구), 가계금융복지조사(공적이전 항목별), 인구주택총조사 표본(통제), 청년삶실태조사, 노인실태조사.
- 우선: 사회통합실태조사·복지패널·사회조사 2023 조사표 확인 → 수급 유형과 신뢰가 한 데이터에 있으면 개인 단위, 없으면 시군구 집계로.
- 메뉴는 유한하게(종속 3 × 독립 묶음 조합 × 매개 0~1). R로 전 조합 추정 → `model/results/*.json`. 원자료는 레포 밖.

### 4-5. API 사용

- 키: Apps Script 스크립트 속성. 콘솔 워크스페이스 범위 키, 이름 `week11-seminar`, 지출 한도, 발표 후 삭제.
- 사전: 조합별 기본 리뷰 생성·캐시. 코퍼스 자동 코딩.
- 실시간: 학생 연구질문 1줄 맞춤 코멘트만. 실패 시 캐시 리뷰로 대체.
- 프롬프트 규칙: 제공된 논문 목록 밖은 언급 금지, 인과 표현 금지("영향을 미친다" 대신 "관련이 있다"), 합쇼체.

## 5. 선행연구 코퍼스

### 5-1. 수집 경로

1. 5편을 인용한 후속 연구(가장 중요)
2. KCI 국내 연구: "사회자본 결정요인", "사회적 신뢰 영향요인", "제도신뢰 대인신뢰", "복지 수급 경험 신뢰", "주민참여 사회자본"
3. 신뢰·사회자본 결정요인 리뷰/메타분석의 참고문헌

목표 80~150편. 1차 30편으로 기준 확인 후 확대.

### 5-2. 스키마 (`corpus/studies.csv`)

```
id,authors,year,title,journal,link,country,data,unit,dv_type,dv_measure,iv_institution,iv_individual,iv_region,iv_network,mediator,moderator,design,result_direction,lineage,verified,notes
```

- `unit`: individual / region / country
- `dv_type`: generalized_trust / institutional_trust / participation / other
- `iv_*`: 해당 묶음의 구체 변수(없으면 빈칸)
- `design`: cross_section / panel / quasi_experiment / experiment
- `lineage`: krishna / freitag / lw / mettler / kr / none
- `verified`: Ji가 링크를 열어 확인한 경우만 TRUE. 수업 페이지에는 TRUE만 노출.

### 5-3. 작업 방식

초록 수집 → API로 칸 자동 채움 → Ji 검수 → verified 표시. 매칭은 `dv_type`·`unit` 일치 + `iv_*` 묶음 겹침 수 + `mediator` 일치로 점수화, 상위 3~5편.
