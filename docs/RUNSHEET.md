질문 → 10초 기다림 → 선택지 둘을 다시 말함 → 5초 → "저는 ○입니다. 이유는 ○입니다." → 다음 쪽. 지명 무응답도 같다. 같은 사람을 두 번 연속 지명하지 않는다(지명 4·5는 같은 사람이므로 4에서 무응답이면 5는 예비 인원으로).

**3-3. 시간 초과 — 삭제 순서(DECK 집계)**
① 개념 확인 투표 절반(말로만 묻기) → ② p.25 700년 → ③ p.39 각주 15 → ④ p.34 교수님 초대. 딜레마는 ★ 쪽이지만 편마다 하나는 남기고, 4분을 3분으로 줄인다.

**3-4. 교수님 개입**
쪽을 고정하고 끝까지 듣는다. 길어지면 다음 점검 시각에서 삭제 순서를 적용한다. 교수님 질문에 바로 답하기 어려우면 "엔딩 표에서 다시 받겠습니다"로 넘기고 p.61에서 받는다.

**3-5. 장비**
노트북 문제 → USB의 PDF 사본을 강의실 PC로(투표·시뮬은 손들기). 프로젝터 문제 → 덱 없이 정리 카드 5장을 계획서로 보며 진행.
