# 1부 구성안 v3 — 흐름 지도 → 논문 5편 깊이 → 끝에 배속 시뮬레이션

2026-10-17 Ji 결정 반영. 이 문서는 **구성안**이다. 장면별 대사는 논문 정리본(docs/papers/0N_*.md)을 다섯 편 다 만든 뒤 SCENARIO_PART1 v3으로 옮긴다. v2(SCENARIO_PART1.md)의 대사·표·참여 질문은 재사용하되 구조는 이 문서가 우선한다.

## 0. 결정 사항 (바꾸지 않는다)

1. 시뮬레이션은 **1부 끝**에 한다. 강의 중에는 시뮬 화면이 한 번도 안 나온다.
2. 시뮬은 **배속**이다. 논문당 사건 하나, 다섯 사건. 선택 사이 세월은 자동으로 흐른다. 한 번 도는 데 2~3분.
3. 실행은 **무대 모드**(1부 끝, 한 분이 나와서) + **각자 모드**(쉬는 시간, 폰) 둘이다.
4. 강의 부분은 앞선 발표자 중 박민지·장진·한예리·최혜민의 관행을 따른다. 논문마다 세 문장 → 짚기(충실) → 현실 딜레마(폰 투표) → 비판적 검토 → 연결.
5. 오프닝은 사회자본 흐름 지도(시기별 로드맵 + 분파 + 5편 인용표). 80억 분의 1 훅은 오프닝이 아니라 무대 모드 앞에 둔다.
6. 폰 투표(딜레마)는 시뮬과 **다른 단순 화면**(vote.html)이다. 시뮬 별명과 투표는 무관.
7. 2부는 따로 고민한다. 이 문서는 2부를 정하지 않는다.
